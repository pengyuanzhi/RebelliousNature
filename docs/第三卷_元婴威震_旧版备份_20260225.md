# 第一百五十一章 元婴初期的力量

时间：出关后第一天
地点：玄天宗·苦海峰
人物：秦寒

清晨的阳光洒在苦海峰上，给整座山峰镀上一层金色的光辉。

秦寒站在观景台上，深吸一口气，感受着体内澎湃的灵力。

"元婴初期……"他喃喃自语。

经过三个月的闭关，他终于突破到了元婴初期。这个境界的力量，远非金丹期可比。

他闭上眼睛，神识如潮水般向外扩散。

方圆百里的一草一木，都清晰地呈现在他的感知中。远处的风吹过树梢，草丛中的虫鸣，甚至地下深处的水流，都尽收眼底。

"神识范围是金丹期的十倍。"秦寒满意地点头。

元婴期最大的变化，就是神识的蜕变。金丹期的神识只能覆盖方圆十里，而元婴初期就能覆盖百里。而且神识的强度和精纯度，都大幅提升。

他催动灵力，丹田中的元婴缓缓飞出。

元婴只有三寸大小，与秦寒的本体一模一样，只是通体透明，散发着淡淡的金光。这就是修士的第二次生命，即使肉身被毁，只要元婴逃脱，就能夺舍重生。

"元神出窍！"

秦寒控制着元婴，从眉心飞出，悬浮在空中。

元婴的速度极快，转眼间就遍历了整个洞府。它穿墙而过，没有任何阻碍。这种能力，可以用来探查敌情，也可以用来偷袭。

"有了元神出窍的能力，战斗时的手段更多了。"秦寒若有所思。

他收回元神，继续感受元婴初期的力量。

体内的灵力比金丹期精纯数倍，运转速度也更快。一招一式，威力都大幅提升。

"现在的我，可以轻松击败元婴初期的修士。"秦寒自信道，"甚至，与元婴中期也能一战。"

他试着施展《苦海经》的法门。

灵力按照《苦海经》的运转路线流转，在体内形成一个个小循环。每一次循环，灵力都会凝练一分。

"《苦海经》在元婴期的威力更大了。"秦寒满意地点头。

《苦海经》是道阶心法，越到后期，威力越强。在金丹期时，它只是让秦寒的修炼速度更快。到了元婴期，它开始展现出真正的威力。

就在这时，一道神识从洞天峰传来。

"出关了？"洞天真人的声音在秦寒脑海中响起。

"是的，师父。"秦寒恭敬道。

"来洞天峰一趟，为师要看看你的修为。"

"是，师父。"

秦寒驾驭苦海飞舟，向洞天峰飞去。

洞天峰是玄天宗的主峰，也是洞真人的修炼之地。秦寒降落在峰顶的广场上，看到师父正站在那里等待。

"拜见师父。"秦寒恭敬行礼。

"起来吧。"洞真人摆手，"让为师看看你的修为。"

洞真人的神识探入秦寒体内，仔细检查。

片刻后，他脸上露出赞赏的笑容。

"元婴初期，根基扎实，灵力精纯。"洞真人点头，"不错，三个月突破元婴，而且根基如此扎实，你是我见过最有天赋的弟子。"

"都是师父教导有方。"秦寒谦虚道。

"不必谦虚。"洞真人摆手，"虽然为师指导了你，但能够突破，全靠你自己的努力。"

"师父，元婴初期之后，该如何修炼？"秦寒问道。

"元婴期分为初期、中期、后期三个小境界。"洞真人说道，"从初期到中期，需要凝练元婴，让元婴从虚幻到凝实。从中期到后期，需要感悟法则，为突破化神期做准备。"

"感悟法则……"秦寒若有所思。

"是的。"洞真人点头，"化神期需要领悟法则才能突破。元婴后期虽然不强求法则，但提前感悟，对突破化神期有很大帮助。"

"弟子明白了。"

"对了。"洞真人像是想起了什么，"你现在元婴初期，可以接一些更高级的任务了。任务堂有一些元婴期的任务，奖励丰厚，而且能历练战斗。"

"多谢师父提醒。"秦寒道。

"去吧，好好修炼。"洞真人拍了拍秦寒的肩膀，"为师期待你早日突破元婴中期。"

秦寒恭敬行礼，离开了洞天峰。

回到苦海峰后，秦寒思考着接下来的修炼计划。

"当务之急，是稳固元婴初期的修为。"秦寒喃喃自语，"然后接取一些任务，历练战斗。"

他决定明天去任务堂看看，有哪些合适的任务。

# 第一百五十二章 洞天新任务

时间：出关后第一天
地点：玄天宗任务堂
人物：秦寒、任务堂执事

第二天，秦寒前往任务堂。

任务堂位于玄天宗的山门处，是一座宏伟的建筑。每天都有无数修士来这里接取任务，提交任务。

秦寒走进任务堂，里面人声鼎沸。

有的修士在查看任务列表，有的在提交任务，有的在领取奖励。整个大厅热闹非凡。

秦寒走到柜台前。

"这位长老，请问有什么可以帮您？"执事恭敬地问道。

虽然秦寒看起来很年轻，但修为达到元婴初期，在玄天宗已经是长老级别。执事不敢怠慢。

秦寒取出长老令牌，递给执事。

执事看到令牌，态度更加恭敬。

"原来是秦长老。"执事说道，"秦长老现在是元婴初期，可以接取元婴期的任务了。"

"有哪些元婴期的任务？"秦寒问道。

执事拿出一个玉简，递给秦寒。

"这是元婴期任务列表，长老可以看看。"

秦寒神识探入玉简，查看任务列表。

玉简中记录着数十个元婴期的任务，每个任务都有详细说明和奖励。

"猎杀元婴初期魔兽，一只奖励一万上品灵石。"
"探索二级秘境，奖励五万上品灵石。"
"探索三级秘境，奖励十万上品灵石。"
"护送商队到邻界，奖励三万上品灵石。"
"炼制元婴期丹药，一枚奖励五千上品灵石。"
"炼制元婴期法宝，一件奖励两万上品灵石。"

秦寒心中盘算。

"猎杀魔兽虽然奖励不错，但对修为提升帮助不大。"
"炼制丹药和法宝，我的技艺还不够。"
"护送商队相对安全，但收益较低。"

"还是探索秘境吧。"秦寒做出决定，"秘境中不仅有珍贵的材料，还能历练战斗。"

"不过，三级秘境危险性太高，可能有元婴后期的魔兽，甚至化神期的妖兽。我现在的实力，勉强能探索二级秘境。"

秦寒看向执事，"我接这个任务：探索二级秘境'暗影秘境'。"

"好的，长老。"执事登记后，递给秦寒一个令牌，"这是任务令牌，探索秘境后，收集一些珍贵材料，就可以提交任务。"

"多谢。"

秦寒接过令牌，转身离开任务堂。

回到苦海峰后，他查看暗影秘境的详细信息。

暗影秘境是一处二级秘境，位于玄天洞天东部，是一片阴暗的森林。秘境内有各种元婴期的魔兽和妖兽，还有很多珍贵的灵草和材料。秘境内部光线昏暗，能见度极低，非常危险。

"暗影秘境……"秦寒若有所思。

他准备一下，带足丹药和符箓，然后驾驭苦海飞舟，向东飞去。

# 第一百五十三章 秘境探险

时间：接任务后
地点：暗影秘境
人物：秦寒、秘境魔兽

苦海飞舟飞了整整一天，终于到达暗影秘境。

秦寒降下飞舟，小心翼翼地进入秘境。

刚进入，他就感受到一股阴冷的气息。这里的天空被浓密的树冠遮蔽，阳光无法穿透，整片森林笼罩在黑暗中。

"好阴暗的地方。"秦寒皱眉。

他开启命轮眼，神识全开。

命轮眼在黑暗中也能看清，秦寒观察到周围的一切。

秘境内的树木高大，每一棵都有数十丈高。树干粗壮，需要数人合抱。树枝交织，形成一张巨大的网，遮天蔽日。

森林中弥漫着浓雾，能见度极低。即使是命轮眼，也只能看清方圆百米。

"难怪叫暗影秘境。"秦寒暗道。

他小心翼翼地前进，时刻警惕着周围的动静。

元婴期的魔兽可能随时出现，必须小心。

走了一柱香的时间，秦寒忽然停下了脚步。

前方传来一阵沙沙声，像是有什么东西在移动。

"有人？"秦寒心中警惕。

他神识探查过去，发现不是人，而是一只魔兽。

那是一只黑色的豹子，体型庞大，有三丈长。它的皮毛在黑暗中几乎看不见，只有一双眼睛闪烁着绿光。

"元婴初期魔兽。"秦寒判断。

暗影豹，二级魔兽，擅长潜伏和偷袭。在黑暗的环境中，它的战斗力会大幅提升。

"既然遇到了，就解决了它。"秦寒喃喃自语。

他取出苦海剑，剑身闪烁着寒光。

暗影豹也发现了秦寒，它低吼一声，向秦寒扑来。

速度极快，眨眼就到了秦寒面前。

"反应不错。"秦寒冷静道。

他侧身一闪，避开暗影豹的攻击。然后一剑刺出，直取暗影豹的要害。

暗影豹反应也很快，它一个翻滚，避开秦寒的剑。

然后它再次扑来，张开大嘴，露出锋利的牙齿。

"雕虫小技。"秦寒冷道。

他催动灵力，苦海剑爆发出强大的剑气。

剑气如虹，直接斩在暗影豹身上。

暗影豹发出一声惨叫，倒在地上。

它的皮毛很坚韧，但在苦海剑的剑气面前，依然被斩开。

秦寒走上前，一剑刺穿暗影豹的头颅。

暗影豹彻底死亡。

"第一只元婴初期魔兽。"秦寒满意地点头。

他取下暗影豹的尸体，收入储物戒。

"继续前进。"秦寒继续探索秘境。

# 第一百五十四章 秘境收获

时间：进入秘境三小时后
地点：暗影秘境深处
人物：秦寒

秦寒继续深入暗影秘境。

这三小时内，他又遇到了五只元婴初期魔兽，全部轻松斩杀。

"暗影秘境的魔兽确实不少。"秦寒喃喃自语。

不过，他不是来猎杀魔兽的，而是来收集材料的。

他仔细观察周围，寻找珍贵的灵草和材料。

暗影秘境虽然阴暗，但正因如此，这里生长着很多喜阴的灵草。

"那是……"秦寒眼睛一亮。

前方不远处，有一株黑色的灵草，散发着淡淡的荧光。

"夜幽草。"秦寒认出这株灵草。

夜幽草是炼制元婴期丹药的材料，一株在市面上能卖到一千上品灵石。

秦寒小心翼翼地走过去，将夜幽草挖出。

"收获不错。"秦寒满意道。

他继续寻找，又发现了数株夜幽草，还有一些其他珍贵材料。

三小时后，他的储物戒中已经有了数十株灵草，以及不少珍贵材料。

"差不多了。"秦寒准备返回。

就在这时，他忽然感受到一股强大的气息。

这股气息很恐怖，至少是元婴后期。

"有大家伙。"秦寒心中警惕。

他躲在树后，悄悄观察。

前方不远处，一只巨大的黑虎正在吃一只魔兽。黑虎有五丈长，浑身漆黑，只有额头有一个王字，闪烁着金光。

"元婴后期魔兽。"秦寒判断。

暗影魔虎，二级魔兽中的霸主，实力强大。正面战斗的话，秦寒没有把握。

"还是避开吧。"秦寒决定。

他悄悄后退，准备离开。

但就在这时，暗影魔虎忽然抬起头，看向秦寒的方向。

"被发现了。"秦寒心中一紧。

暗影魔虎发出一声怒吼，向秦寒冲来。

速度极快，眨眼就到了。

"没办法了，只能一战。"秦寒取出苦海剑。

他催动灵力，施展苦海剑法。

"苦海剑法——第一式！"

一道巨大的剑气斩向暗影魔虎。

暗影魔虎也不弱，它张开大嘴，喷出一道黑色的光波，与剑气碰撞。

轰！

两股力量碰撞，发出巨大的爆炸。

秦寒被震退数步，暗影魔虎也被震退数步。

"果然强大。"秦寒暗道。

他再次催动灵力，施展更强的法术。

"苦海剑法——第二式！"

剑气更加凌厉，斩向暗影魔虎。

暗影魔虎再次喷出光波，但这一次，它的光波被剑气斩散。

剑气斩在暗影魔虎身上，留下一道深深的伤口。

暗影魔虎发出一声惨叫，愤怒地冲向秦寒。

"来得好。"秦寒不退反进。

他催动《苦海经》，灵力瞬间提升。

"第三式！"

最强的剑气斩出，直接斩断暗影魔虎的头颅。

暗影魔虎倒在地上，彻底死亡。

"元婴后期魔兽，终于斩杀了。"秦寒松了一口气。

他取下暗影魔虎的尸体，收入储物戒。

"收获丰富。"秦寒满意道。

"是时候返回了。"

# 第一百五十五章 宗门贡献

时间：返回玄天宗后
地点：玄天宗任务堂

# 第二百章 返回中界

时间：通过传送阵后
地点：中界·玄天洞天
人物：秦寒、洞天真人

秦寒穿过传送阵，来到了中界。

他发现自己身处玄天洞天的一座山峰上。

"回来了。"秦寒深吸一口气，感受着中界浓郁的灵气。

中界的灵气浓度，是下界的十倍以上。在这里修炼，速度会快很多。

"寒儿？"一个熟悉的声音传来。

秦寒转头，看到洞真人正站在不远处。

"师父。"秦寒恭敬行礼。

"你回来了。"洞真人笑道，"听说你在下界大显神威，斩杀了血煞老祖、阴尸老祖、血影老魔、鬼面真人四大元婴期修士？"

"侥幸而已。"秦寒谦虚道。

"不必谦虚。"洞真人摆手，"能以元婴中期的修为，斩杀四大元婴期修士，这可不是侥幸能做到的。"

"你的实力，已经不输给元婴后期了。"

"对了，"洞真人忽然道，"你的修为……"

"弟子已经突破元婴后期了。"秦寒道。

"什么？"洞真人惊讶，"元婴后期？"

"是的。"秦寒点头。

"好，很好！"洞真人高兴道，"你的天赋，确实是我见过最好的。"

"不过，"洞真人话锋一转，"中界的危险程度，远超下界。你虽然是元婴后期，但也不能大意。"

"弟子明白。"秦寒道。

"对了，"洞真人道，"你离开的这段时间，中界发生了一些事情。"

"什么事？"秦寒问道。

"魔族的异动越来越频繁。"洞真人道，"虽然我们封印了异界通道，但魔族似乎在寻找其他的方法入侵我们的世界。"

"魔族……"秦寒眼中闪过一丝凝重。

"是的。"洞真人点头，"所以，你必须尽快提升实力，做好迎接更大挑战的准备。"

"是，师父。"秦寒道。

"好了，你先回去休息吧。"洞真人道，"明天再来找我，我们详细谈谈接下来的计划。"

"是，师父。"

秦寒离开洞天峰，回到自己的苦海峰。

站在苦海峰上，秦寒望着远方。

"中界……"他喃喃自语。

"新的挑战，开始了。"
